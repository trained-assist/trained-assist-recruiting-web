# R-03 legacy source projection, offline stage 2

`projectLegacyR03Sources` converts the old HH JSON shapes into the private metadata envelope accepted by `R03LegacyRehearsal`: `all-candidates.json`, per-vacancy `seen-ids.json`, dated `search-results-*.json`, `queries-*.json`, `candidate-comments-*.json`, and `ats_config:<vacancy>.json` context wrappers. It also accepts already reviewed, metadata-only paused schedule definitions. Tests use invented names, IDs, comments and queries.
The ATS wrapper accepts the historical double-serialized JSON `value` and checks any embedded vacancy ID against the filename scope.

`readLegacyR03ProfileFiles` is a read-only adapter for an **already frozen private backup**. It reads the recognized files from explicit proactive/context directories, rejects symlinks and ambiguous unscoped or malformed source filenames, and returns keyed HMAC byte receipts alongside the projected profile. The HMAC key and input paths belong to the private operator environment; no CLI prints the envelope. Snapshot IDs and content remain in the private process only.

The projection keeps resume and vacancy references solely for linkage checks. It discards candidate names and resume fields, query strings, comment text and ATS content. It preserves an empty `vacancy_ids` as a wildcard for explicit operator review. Historical snapshot files have no durable job ID, so the projector derives a stable **migration reference** from source profile, filename and timestamp. This reference is not an accepted search receipt and must never make an unknown scheduled or manual result appear fresh.

The operator must supply an independent, read-only source backup manifest and expected counts, map source profiles/vacancies to target owners, and run this code only in private restricted storage. `legacyR03ExpectedCounts` reports projected counts for comparison; using it as the sole expected-count input would hide missing source files. Compare HMAC byte receipts to the frozen backup manifest as well. The existing rehearsal checks ownership, dangling links, duplicates, schedule pause state and expected counts before it records HMAC fingerprints in a private SQLite file.

This stage does not copy domain data into the live candidate tables, preserve query/ATS text, restore credentials, or enable schedules. A private source backup, final scorer delta, wildcard decisions, transactional content restore, accepted receipt mapping, canary read and rollback remain required for HH #187. No real export or production endpoint is read here.
