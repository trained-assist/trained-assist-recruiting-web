# R-03 real-HH unknown occurrence reconciliation (offline)

`SqliteRealHhReconciler` resolves one quarantined `outcome_unknown` occurrence only when the real-HH candidate snapshot was already committed. This covers a worker crash or lease expiry after snapshot commit and before occurrence success. It is an operator-only domain service: the caller supplies a trusted authorization callback, profile/vacancy ownership callback, operation ID, deterministic occurrence job ID and expected criteria, source and result revisions. All callbacks default to deny. No HTTP/MCP route, HH fetch, candidate re-materialization or automatic retry is added.

The reconciliation transaction verifies the occurrence's exact profile, vacancy, job and criteria binding, the blocked owning schedule, and the completed `scheduled` snapshot's profile, vacancy, job, criteria, source and 24-hex result revision. It also rejects a snapshot timestamp before occurrence start or after reconciliation time. It then marks the occurrence succeeded, unblocks its schedule and writes a versioned receipt under one SQLite `BEGIN IMMEDIATE` transaction. A receipt write failure rolls both updates back. Repeating the same operation ID and command returns the receipt; a changed command or second operation for the occurrence conflicts. The receipt contains no candidate text or credential.

The snapshot keeps its original `searchedAt`. Reconciling an older scheduled run does not change a newer manual snapshot's freshness. A missing or mismatched snapshot remains quarantined and needs investigation; it cannot be made successful through this command. Tests use invented candidate data and cover scope, every revision, missing snapshot, transaction rollback, replay and older freshness. `contracts/v1-real-hh-reconciliation-receipt.schema.json` checks the audit shape.

This still needs a trusted operator interface, backup/retention rules and production profile binding before use on a host. It does not reconcile unknown legacy GCP results without a verified matching real-HH snapshot. The GCP stop gate remains [HH #187](https://github.com/trained-assist/trained-assist-hh-skill/issues/187).
